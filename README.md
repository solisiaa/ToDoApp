# ToDoApp

Минималистичное iOS-приложение «Список задач» на SwiftUI + SwiftData.

## На что делался упор

1. **Персистентность данных (SwiftData).** Единственный источник правды — `ModelContainer` с моделями `Task` и `Category`. Контекст создаётся один раз в точке входа и раздаётся через `@Environment`. Каскадное удаление (`Category` → задачи), уникальные id, сортировка на уровне `FetchDescriptor`.
2. **Полный CRUD-цикл.** Создание через форму с валидацией, чтение с сортировкой (новые сверху) и фильтрами, обновление свайпом и на отдельном экране, удаление свайпом и из экрана редактирования. После каждой мутации список перечитывается из хранилища — UI всегда консистентен с диском.
3. **Чистая архитектура MVVM.** Строгая иерархия `View → ViewModel → Repository → ModelContext`: во View нет ни одного `@Query`, ViewModel не импортирует SwiftData и зависит только от протокола репозитория. Протокол — единственная абстракция, он же точка подмены на мок в тестах и превью.
4. **Современный стек без легаси.** `@Observable` вместо `ObservableObject/@Published`, `NavigationStack`, `ContentUnavailableView`, `swift-testing` вместо `XCTest`, ноль сторонних зависимостей.

## Структура

```
ToDoApp/
├── ToDoAppApp.swift        # @main, ModelContainer, сборка графа зависимостей
├── Models/                 # Task, Category (@Model), Priority
├── Repositories/           # протокол + реализация на SwiftData + мок
├── ViewModels/             # TaskListViewModel (@Observable)
└── Views/                  # список, строка, календарь, формы Add/Edit
ToDoAppTests/               # 16 тестов вью-модели на моке
```

## Функции

- Фильтры Все / Активные / Выполненные
- Календарь: сетка месяца, точки на днях с дедлайнами, фильтр по дню
- Приоритеты с цветовой индикацией, дедлайны, подсветка просрочки
- Свайпы: выполнить/вернуть, удалить, редактировать

## Запуск

1. Открыть `ToDoApp.xcodeproj` в Xcode
2. Выбрать симулятор с iOS 17.0+ (проект настроен на 27.0)
3. `Cmd+R`

Тесты: File → New → Target → Unit Testing Bundle с именем `ToDoAppTests`, добавить файл из папки `ToDoAppTests/`, затем `Cmd+U`.
